# Backend de referência — Podcast Lab

Código copiado do Aulas para estudo e futura adaptação, **não implantado em produção**.

O Podcast Lab não usa a API e o Firestore do Aulas. A futura API deve ter credenciais novas e seu próprio serviço Render e armazenamento.

Não colocar credenciais Firebase no repositório. Enquanto não houver serviço independente, o frontend de Podcast funciona apenas como demonstração audiovisual (sem cadastro e sem gravação nativa).

O arquivo de gravação de podcast **não** é produzido por esse backend no estado atual.
